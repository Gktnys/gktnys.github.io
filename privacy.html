アプリ紹介プライバシーポリシー利用規約

プライバシーポリシー

本ポリシーは、個人利用のWindowsアプリ「kabu station auto login」（以下「本アプリ」）によるGoogleユーザーデータの取扱いを説明します。

1. アクセスする情報

本アプリは、本人のOAuth許可に基づいてGmailの読み取り権限（https://www.googleapis.com/auth/gmail.readonly）を使用します。この権限はメールの読み取りを許可します。実際の処理では、設定された証券会社の送信元と新着時刻で検索し、候補メールのID、差出人、件名、受信時刻、認証ヘッダー、本文を確認します。

Gmailのパスワードを本アプリに入力する必要はありません。本アプリはメールの送信、削除、既読化、ラベル変更を行いません。

2. 利用目的

Gmailの情報は、今回のkabuステーションへのログインに必要な新着認証メールを識別し、ワンタイムキーを取得する目的だけに利用します。過去のメールや使用済みのキーを新しいログインへ再利用しないよう、メールIDや受信時刻などを照合します。

3. 処理・保存と保護

メール本文とワンタイムキーは本人のPC上の処理メモリで一時的に取り扱い、これらをログやデータベースへ永続保存しない設計です。OAuthの認証情報はWindowsのユーザーに紐づく暗号化機能（DPAPI）で保護し、本人のPCに保存します。再認証時には、復旧のため旧設定の暗号化バックアップを同じPCに保管する場合があります。

認証の成否、処理時刻、秘密情報を含まないエラーコードなどの運用記録を保存する場合があります。認証情報の保存は自動的には期限切れになりません。利用停止時には、下記の手順でアクセス許可の取消しと保存データの削除を行えます。

4. 第三者への提供

本アプリは、Gmailのメール内容やワンタイムキーを、広告、販売、一般的なAIモデルの学習、ChatGPTその他のAIサービスへの送信に使用しません。認証のためGoogleと証券会社へ必要な通信を行い、取得したワンタイムキーは本人が利用するkabuステーションの認証画面へ入力します。

本アプリのGoogle APIから取得した情報の利用および他のアプリへの転送は、Google API Services User Data PolicyのLimited Use要件を遵守します。

5. 連携の解除と削除

本人は、Googleアカウントの「サードパーティ製アプリとサービスとの接続」で本アプリへのアクセス許可を取り消せます。ローカルの設定ファイルは取消しだけでは自動削除されません。PC上の自動ログイン処理を停止したうえで、暗号化した認証設定、関連する暗号化バックアップ、不要な運用記録を削除してください。Gmail上の元のメールは本アプリでは削除しません。

6. 説明サイトについて

この説明サイトには、認証フォーム、アクセス解析用スクリプト、広告、アプリ独自のCookieを設置していません。Gmailのメールやトークンをこのサイトへアップロードする機能もありません。ホスティングに使用するGitHub Pagesでは、提供者がセキュリティ目的でアクセス元IPアドレスを記録します。詳しくはGitHubのプライバシーに関する説明をご確認ください。

7. 管理者・お問い合わせ・変更

管理者は、本アプリを個人利用する本人です。お問い合わせやデータ取扱いの確認は、GoogleのOAuth同意画面に表示されるユーザーサポートメールアドレスへご連絡ください。データの取扱いを変更する場合は、このページを更新します。
